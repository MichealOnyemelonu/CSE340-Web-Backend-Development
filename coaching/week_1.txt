One more quick check on this topic before we move on: in Express, when you define multiple app.get() calls like you have, how does Express actually decide which handler function to run for a given incoming request?

Express evaluates routes in the order they are registered. When a request comes in, Express compares the request's HTTP method and URL path against the route definitions and runs the first matching handler.

    const lastModified = document.getElementById('last-modified');
    if (lastModified) {
        const d = new Date(document.lastModified);

            `${pad(d.getMonth() + 1)}/${pad(d.getDate())}/${d.getFullYear()} ` +

Let's zoom in on one particular piece: const isOpen = navList.classList.toggle('open'); followed by toggle.setAttribute('aria-expanded', isOpen);.
Can you explain what classList.toggle() returns, and why you're relying on that return value rather than, say, separately checking whether the class is present with an if statement?

classList.toggle() returns a Boolean value indicating whether the class is present after the toggle operation:

true → the class was added and is now present.
false → the class was removed and is no longer present. I'm using that return value because it lets me both change and check the class state in a single operation. Using a separate if statement with classList.contains() would require an extra check, whereas toggle() already tells me the resulting state, making the code shorter and easier to read.
